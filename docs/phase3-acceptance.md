# 阶段 3：跨产品闭环（2026-10-27）

本阶段只读取本项目和新生成的合成夹具，没有使用公司业务仓库、代码、备份或凭据作为实验输入。原始 provider 输出、运行数据库、下载工具和私有证据全部保留在仓库外。

## 已实现

- Qoder CN 原生 CLI 1.1.80，默认关闭，精确版本和登录检查。stdin 传入任务，禁用工具、设置来源、MCP、会话持久化及模型请求重试；不使用 bypass/yolo。响应必须为单轮成功终态和无 Markdown 的 JSON；额度、权限、认证错误停止，不回退 API。
- Codex 主脑生成指定 worker 的计划；实现前先做诊断和哈希绑定的里程碑审查。越界或要求扩大权限时停止；相同任务/基线的已批准诊断可用于返工。
- 返工将上轮实际 diff、失败测试、审查意见及候选哈希交给 worker；不改原审批计划。候选漂移则拒绝返工。重排队不覆盖历史 attempt 的 rework 状态。
- provider 进程事件与里程碑持久化；里程碑写入校验 fence、attempt、租约和审批。执行时续租，丢失所有权后停止并核对。
- 补齐 Windows 非敏感平台目录环境变量。首个真实流程因 `%SystemDrive%` 未展开而在候选内产生运行时缓存，范围检查正确拒绝；修复环境后在全新夹具重跑，没有放宽范围或忽略文件。

## 真实流程证据

Codex CLI `0.164.0-alpha.11.1` 主脑、Qoder CN `1.1.80` worker：模型规划 → 本地测试程序显式审批 → worker 诊断 → 主脑批准 → 实现 → 独立固定测试 → 独立主脑审查 → 反馈返工 → 再审查 → 集成副本复测 → 导出证据。

为检验真实反馈闭环，可信测试程序明确注入首轮空列表返回 999 的错误；原始模型响应另外保存。第一次审查 rework，第二轮 accept，五个固定用例和集成复测通过。原仓库 HEAD、索引、staged/unstaged/untracked 状态保持不变，候选不含共享 `.git`。错误注入不是 Qoder 模型失败证据。

Qoder 返回 credits，但 token/货币字段为零不足以证明免费。订阅余额、账单和远端 session 停止均未验证，`billing_verified=false`、`production_ready=false`。交换主脑/worker 的方向支持显式选择，但没有进行第二方向真实验收。ACP 未实现。

## Claude CLI 与 TRAE

按用户授权，从官方 npm 平台包下载 Claude Code `2.1.311`，校验 SHA512；不执行第三方安装脚本。验证后安装到用户目录 `.local/bin`，补齐用户 PATH，未修改系统 PATH。CLI 使用已有 CC Switch 用户配置，自定义 API 实际模型为 `glm-5.3[1m]`，不能称为 Anthropic Claude 模型验收。工具、MCP、自定义命令和会话持久化关闭，只审查合成内容；未提取或复制 token。

本轮授权单次最多 0.10 美元、总计 0.30 美元；调用前按每次 0.10 美元预留，达到总额后停止。CLI 报价是本地估计，不能证明代理账单的硬上限。一个连通性样例通过；首次独立审查虽返回 accept，但证据引用超出契约而被程序拒绝。因此为审查 schema 增加引用枚举，并在最后一份预算内重新验证。第二次审查的引用正确，但输出带 Markdown 围栏，仍被严格 JSON 契约拒绝。没有剥除围栏冒充自动验收通过，也没有继续收费重试。

三个调用的 CLI 报价分别为 0.003272、0.040857、0.039672 美元，总计约 **0.083801 美元**，累计预留 **0.30 美元**；没有剩余可分配调用预算。Claude CLI 连通性已验证，独立审查文本两次认为修复正确，但结构化审查接入未通过验收。后续应在新的明确预算内验证原生结构化输出模式，不能用文本上的 accept 代替调度器验收。

Claude 没有接入自动调度或 API fallback。TRAE 按用户要求跳过，不执行桌面自动化，不把下载工具或桌面已安装当作 smoke 通过。没有新增第三方 MCP，官方 CLI 已满足本次路径。
